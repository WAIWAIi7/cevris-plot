# 0.8.x 安装修复验收

0.8.1 补充验收：81 项自动测试全部通过。用智能体实际附带的无 npm Node 启动安装，自动下载并解压完整私有 Node、安装生产依赖、复用显式外部 R，四格式绘图和随后离线重装均通过。R 的首次启动临时目录位于可写的应用目录，不再继承已被清理的路径。0.8.0 发布的六个文件已匿名重新下载并逐一核对 SHA-256；0.8.1 的发布下载复核以发布页记录为准。

在 Windows x64、Windows PowerShell 5.1、Node 24.22.2、R 4.6.2、ggplot2 4.0.3 下验收。

| 项目 | 已完成验证 |
|---|---|
| 自动回归 | 80 项通过，含数据导入、绘图、项目保存、下载重试、超时、校验失败、ZIP 路径安全及宿主注册 |
| R 模板 | 105 种实际渲染、四种图片格式及参数效果通过 |
| R 源码 | 105 个独立导出脚本逐一执行通过 |
| 全新文件部署 | 从生成的发布包及预置 Node/R/解包器文件安装，R EXE 未执行；安装目录包含空格及较深路径 |
| 外部环境 | 外部 Node/R 配置及显式 R 库复用，配置在后续 CLI/网页进程可读取 |
| 离线重复安装 | 无下载、无 npm 重装、无前端重建；用户数据和原始前端文件保持不变 |
| 系统写入 | 全新安装及重装前后，R 的 HKCU 卸载注册项、R 开始菜单目录和 Cevris Plot 入口快照不变 |
| 构建失败 | 故意移走 esbuild 可执行文件，显式重建失败后保留已编译网页，实际四格式绘图仍通过 |
| TLS | 运行库和 CRAN 包采用 Node/OpenSSL；真实完成全新 R 包下载与包内文件校验；故障测试覆盖断线、404、超时和错误摘要 |
| Skill | 元数据验证通过；注册入口测试覆盖目录空格、重复注册及另一安装的覆盖保护 |

生产依赖拆分后，本机测得 Node 约 102.4 MiB、R 本体 186 MiB、所需 R 扩展库 84.6 MiB、运行用 npm 包 41.4 MiB、编译网页与示例 5.3 MiB。合计约 420 MiB，另加少量应用源码，不含用户项目、绘图缓存、首次下载峰值和系统字体。外部环境复用时无需重复占用对应组件；这些数值不是各版本/机器的固定保证。

新的 GitHub 工作流增加独立的 Windows 文件部署与离线重装任务，云端结果以对应提交的 Actions 为准。

边界：未获得反馈方两份 D 盘报告原件，本轮根据用户粘贴的复现摘要修复。未在反馈方具体 DSH 受限令牌或未指定版本的豆包客户端直接执行；“注册表快照不变”和通用宿主测试不等于这两种客户端的端到端认证。宿主仍需允许 Node/R 子进程和目标目录写入。没有修改 ACL、提升权限或关闭证书验证。
