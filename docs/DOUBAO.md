# 豆包官方电脑版接入

目标是豆包官方电脑版中的「豆包工作 / 办公任务」能力，使用用户自己的豆包账户。Cevris Plot 不调用豆包模型 API、不要求用户交出模型密钥。

## 本地工作流

发布页另提供 `cevris-plot-doubao.zip`，包含专用 Skill 入口、应用代码、预编译网页、图标和版本元数据。Node/R 不放进技能压缩包，首次运行在用户允许的可写目录准备环境。具备本地技能导入入口的客户端可选此 ZIP；若客户端只提供技能商店，则需通过平台上架后安装，不能把任意隐藏目录当成官方导入机制。

技能载入后应使用实际可用的本地终端/文件工具：定位包目录，确认 Windows x64，在可写目录执行 `scripts/install.ps1`；已有环境先执行 `scripts/figure.mjs doctor`。资源目录只读时，把应用文件复制到用户允许的工作目录再部署，不修改宿主目录权限。安装参数、Node 缺少 npm 的修复和外部 R 复用见 [安装说明](INSTALLATION.md)。

用户给出数据和实验背景后，按包内 SKILL.md 选择配方、准备 spec、实际执行 `draw`，交付图片与 `.figure.json`；需要微调则 `open --browser false`，返回本机网页链接。上传文件必须使用宿主实际给出的本地路径，不能把云端附件标识当作 Windows 路径。若当前任务只有远程容器或网页工具，明确说明缺少本机执行能力，交付可导入的数据/项目，不宣称已经操作用户电脑。

## 官方技能商店流程

依据 [豆包开放平台技能接入指南](https://open.doubao.com/document/doubao-developer-guide/skill-integration-guide)（核对日期 2026-11-05）：开发者需企业认证，上传 ZIP，完成平台静态校验、评测材料和审核后，才能供终端用户从技能页面安装。本仓库的 GitHub 发布不等于豆包商店上架。

打包器按公开限制检查：压缩包及解压内容均不超过 16 MB、条目不超过 1024、单文件不超过 2 MB，并包含名称、简介、版本和图标。采用标准 SKILL.md 的 metadata 记录附加字段；公开指南未完整说明其解析字段映射，仍须在开发者控制台核对。不能将本地格式检查称为平台审核通过。

可用于平台验收的示例任务：

1. 使用模拟根长数据，绘制带原始点的柱状图，返回 PNG 和可编辑项目。
2. 根据我提供的实验分组和 CSV，选择图形；对不明确的配对关系先澄清。
3. 绘制横向云雨图，字体 Times New Roman，使用指定配色。
4. 根据已有差异分析结果绘制火山图，不重新编造 p 值。
5. 把两张同模板图统一参数，导出组图和独立 R 源码。
6. 不打开窗口，将当前项目交接到本地网页，返回编辑链接。
7. 断网后使用已安装环境再次绘图，保留原始数据和旧项目。
8. 复用指定的外部 R；不要运行 R 安装器或改注册表。

已验证：打包限制、技能元数据、本地 CLI 和 Windows 安装/绘图流程。尚未验证：豆包实际客户端加载、工具授权、附件交付、平台解析与商店审核；这些需要对应客户端或开发者账户，不能用通用 CLI 测试代替。
