# 雾蓝科研绘图工作室 · 0.5

用户：不编写代码的科研人员。主任务是把自己的实验数据变成可以逐项调整、导出和复现的图。

## 方向

把图形当作工作台上的作品，给它稳定且宽阔的中央空间。深蓝窄侧栏提供全局定位，浅蓝数据摘要和参数面板分列两侧。图表库是可检索的图谱，不是首页营销卡片墙。

配色：雾蓝底 #E5EDF4；面板 #F0F5F9；输入底 #E8F0F6；海蓝强调 #315F7D；深蓝导航 #203D53；正文 #213B50。警告使用独立语义色。禁止联网字体及纯白大片背景。

字体：界面使用本机微软雅黑 / 苹方，数字使用等宽数字特性；标题24–30px，正文14px，辅助12px。图内字体由项目参数管理，界面改版不改用户图形。

布局：

```text
窄导航 | 项目标题、保存状态                         保存 / 导出
       | 当前图形和数据 | 图形工具栏 + 大画布 | 分类参数 + 搜索
       | 整理 / 换图   | 图形状态 + 尺寸     | 重置单项 / 样式
```

图表库：分类侧栏 / 搜索和图谱 / 所选图详情。中等屏幕将详情变成可关闭抽屉；手机将分类折叠成选择器，所有动作仍可键盘完成。

## Skill建议与取舍

使用 frontend-design 与 ui-ux-pro-max。第一次设计系统查询返回新拟态健康应用，和本项目不匹配，弃用。限定数据面板后返回的高密度信息组织、筛选和清晰焦点适用；营销首页、亮橙强调和远程字体不适用。保留用户选定雾蓝色，采用低装饰、明确层次的编辑器布局。

## 交互

- 全局导航始终可见，页内浏览支持浏览器后退；快捷键不接管输入框的撤销。
- 参数按外观、文字、布局、数据、计算分组；可跨分组搜索；所有滑块保留数值输入与单项重置。
- 预览可专注查看，缩放不改变导出尺寸；数据摘要可直接进入映射。
- 图库支持分类、关键词、收藏、最近使用、网格/列表；小屏详情可关闭，使用示例后返回编辑器。
- 网络断连提示如何启动本地服务，自动重试/手动重连；不把服务器停止当作外网问题。
- 图形计算、原始数据、项目与样式存储保持原协议。避免用假占位功能或空按钮填界面。

## 审阅标准

真实网页截图验证桌面、窄屏和手机。检查选图→示例→映射→参数→导出、保存、键盘焦点、断连恢复。对比度至少4.5:1；减少动态效果设置下禁用动画。
